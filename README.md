# Speech-Signal-Basics
Key Concepts of Waveforms, Sampling, and Quantization

This repository covers key concepts in speech signal representation, including waveforms, sampling, and quantization. It contains code for visualizing and experimenting with speech signals, as well as demonstrating the effects of different sampling rates and quantization techniques.
